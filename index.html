Keyboard shortcuts

Map-first controls (ignored while typing in fields).

  • / or S Focus search
  • I Toggle filters
  • O Toggle options menu
  • L Locate me
  • F Fit all markers
  • R Random listing
  • D Toggle dark mode
  • V Toggle favorites only
  • ↑ / ↓ Navigate list
  • Enter Open highlighted listing
  • ? or H This help
  • Esc Close cards / modals / panels

Works in seed/demo and live modes. See Options → Shortcuts anytime.
